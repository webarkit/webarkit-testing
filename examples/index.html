WebARKit Examples

Browser AR examples for the WebARKit tracking library.

Feature-tracker example

Lightweight 2D demo: consumes only the marker homography (getHomography()) and the warped marker corners (getCorners()). The blue rectangle outlines the detected marker and the AR image is positioned via CSS matrix3d. There is no 3D pose and no real camera calibration, so the overlay is less precise (a small size offset around the printed marker is expected).

  • All trackers — unified — pick Teblid / AKAZE / ORB / FREAK from a dropdown.

three.js AR examples

Full 3D AR: consumes the corrected right-handed GL modelview matrixGL_RH plus the camera projection from the library, and renders content (cube + axes) with three.js. More precise placement than the 2D feature-tracker example.

  • Teblid — static image — AR overlay on a still image, Teblid tracker.
  • Teblid — webcam — live camera AR, Teblid tracker (bufferCopy ping-pong).
